# Primera activación de GitHub Actions — V3 PRUEBAS

Esta actualización documental se utiliza para activar la verificación automatizada y solicitar aprobación del entorno `v3-pruebas`.

- Destino: solo el Apps Script V3 de pruebas.
- La verificación de archivos no modifica Google Sheets.
- La sincronización se ejecuta solo después de aprobar el job de despliegue del entorno.
- No se actualiza la versión publicada `/exec`; únicamente el código de desarrollo `/dev`.
- Revisar `Actions` en GitHub para confirmar el resultado y **no presionar Approve si el workflow muestra una rama o proyecto inesperados**.

No agregar contraseñas, tokens, nóminas ni datos del personal al repositorio.
